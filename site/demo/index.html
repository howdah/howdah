Howdah in your browser

This page runs the real Howdah core, compiled to WebAssembly, inside your browser. Nothing is sent anywhere: there are no network requests besides loading this page's own files, and no trackers. It is a demonstration on made-up sample requests, not a scan of your own server.

The samples are harmless: each body is built here from a structural description (counts and shapes), and contains no exploit code. Howdah runs in its default block mode.
